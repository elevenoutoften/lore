Action Buttons

Pink CTAs, rose outline actions, ghost text actions, and danger actions. One primary size; the icon and close controls are separate square utilities.

Primary rose buttons

board/settings/brandbook
  • One filled rose CTA for the primary action on a surface.
  • Single size — pair with secondary or ghost for lower-emphasis actions.

Secondary rose outline

board/settings
  • Rose outline for secondary actions that still need presence.
  • Also used as the embedded action inside the note-compose field.

Ghost and utility actions

board/settings
  • Low-emphasis text action for cancel, revoke, and inline row actions.
  • The square icon button is a separate utility token.

Editor actions

ideas
  • The standard ghost / danger / primary trio inside an editor.
  • Only layout differs — e.g. a destructive action sitting on the left.

Danger action

settings/ideas
  • Transparent red outline with an error-tinted background on hover.
  • Use for destructive actions like delete or archive.
