# Frontmatter Reference

Every sample page includes `title`, `kind`, and `visibility`.

Common optional fields:

- `summary`: one-sentence page summary.
- `status`: lifecycle marker such as `draft`, `active`, or `accepted`.
- `tags`: list of searchable tags.
- `sources`: source documents or URLs.
- `source_paths`: repository file paths referenced by the page.
- `trigger`, `preconditions`, and `postconditions`: procedure metadata.

Use this reference with [[Getting Started|getting-started]] and
[[Components|architecture/components]] when creating new pages.
